# Mainline A — Gaia deep-space art and knowledge

This six-stage line keeps the existing physics runtime unchanged while adding a source-grounded presentation layer.

| Stage | Scope | Exit evidence |
|---|---|---|
| A1 | Unified data, art, narrative, provenance contract; coverage inventory | Contract, inventory, first object set, checks pass |
| A2 | Common constellations | Boundary/asterism data, labels, art, per-object source cards |
| A3 | Nebula art and multiband interpretation | Licensed asset manifests, band notes, calibrated visual states |
| A4 | Stellar art and detailed introductions | Gaia-linked records, presentation profiles, uncertainty notes |
| A5 | Cross-object observation experience | Constellation–nebula–star links, focus and narrative transitions |
| A6 | Performance, rights, provenance and formal acceptance | Budget traces, license audit, reproducible release packet |

## A1 first implementation set

- Constellations: Orion (Ori), Ursa Major (UMa), Cassiopeia (Cas), Scorpius (Sco).
- Nebulae: M42, M1, M8, M16, M20, M57, NGC 7293, NGC 6543, NGC 2237, Veil, Carina, Horsehead.
- Stars: Alpha Centauri A, Achernar, Betelgeuse, Sirius A, Rigel, Antares.

Formal IAU boundaries and per-image rights remain explicit follow-up items where the current repository has only asterism waypoints or archive-level references.
