## Rendering policy

Render all layers as concentric sky spheres sharing one rotation. The base layer
defines readiness; stars and dust load progressively. Do not add procedural
runtime star noise to Orbit Atlas. v57, v56 and v48 may also sample their negative-space
masks for selected-body subject matte composition; this is a presentation-layer
cue only and does not change camera physics or body positions. Runtime reads only
prepared local `public/textures` assets; development-time source downloads are
not runtime online validation or asset completeness claims.

## Important

Only use strict `2:1` equirectangular JPG/PNG assets for the sky sphere. Regular NASA photos, cropped Milky Way images, or `4:3`/`16:9` wallpapers should not be mapped onto the sphere; use those as low-opacity decorative overlays instead.
