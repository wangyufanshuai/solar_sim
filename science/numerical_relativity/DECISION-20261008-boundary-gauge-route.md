all6 k2 A-vector predictions agree with retained native data. The next work is
an actual boundary-discretization candidate, not another unchanged-domain or
first-stage mechanism audit. This decision does NOT close the T=1M failures.

3. Select a **diagonal-norm SBP/SAT boundary-discretization track** for the next

4. First verify the spatial summation-by-parts identity and scalar incoming SAT

   candidate while isolating the boundary change. If admissible coefficient
   coverage/eigenbasis control fails, stop that candidate and make a separate
   published-gauge decision; do not retune f or mu inside the boundary experiment.

No framework replacement, external deployment, new toolchain installation,

## Why this route

The coupled source reduces to the discrete lapse Laplacian at this initial
slice. Clamping that source at the fixed layers predicts the first observed
auxiliary response. This directs the next change toward compatible boundary
discretization rather than silent term removal or repeated bulk-oracle checks.
It does not prove this source is the sole cause of the later convergence loss.

SBP/SAT is selected as an engineering method with an explicit discrete energy
identity, not because this experiment proves it solves the Einstein problem.
The diagonal norm and derivative coefficients were cross-read from
[SummationByPartsOperators.jl](https://github.com/ranocha/SummationByPartsOperators.jl/blob/main/src/SBP_coefficients/MattssonNordstr%C3%B6m2004.jl),
Git blob793d768b0bb39df2339c63901a7eb300ddbbc779. That primary implementation
attributes the family to Mattsson and Nordstrom (2004), JCP199,503-540.
The new Python operator is an independent small implementation of these
mathematical coefficients; the Julia package is not installed or executed.

For u_t+c*u_x=0 and E=u^T*H*u/2, homogeneous incoming SAT should yield
`E_dot=-abs(c)*(u_left^2+u_right^2)/2`. This is a semidiscrete scalar result.
It does not establish stability of arbitrary RK timesteps, variable coefficients,
curved backgrounds or the full FO system.

## Required next implementation gates

- **Operator gate:** positive norm; exact rational SBP identity for a representative
  grid; constant preservation; degree4 interior/degree2 boundary moments; each
  array axis and packed-variable layout; mirrored-face signs; no input mutation.
- **Coupled frozen gate:** actual formulation matrices and a declared symmetrizer,
  SAT with controlled incoming data, discrete energy/source balance, and CFL/time
  refinement. Full58-slot tests; scalar results cannot promote this gate.
- **Curved/nonlinear gate:** stage-local coefficients, initial-boundary compatibility,
  relevant characteristic regimes, independent constraints, finite positivity,
  outgoing/returning disturbance controls, matched regions and at least3 resolutions.
- **Physical gate:** only after the above, assess a separately frozen single-hole
  configuration containing a horizon; compare horizon/mass/constraints and independent
  physical benchmarks. AMR, binary evolution and waves remain downstream.

The old >=3 FD4 criterion remains unchanged in its old experiment. The SBP(4,2)
candidate needs an explicit new error/order budget; it cannot relabel lower
boundary order as an old success. Failed admission, incompatible coefficients
or an unresolved coupled energy estimate stops candidate integration, not the
entire long-term goal. The fallback decision must be explicit rather than hidden.
