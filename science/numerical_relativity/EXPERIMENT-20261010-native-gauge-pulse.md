## 科学问题与冻结边界

不改变现有 N13 Schwarzschild 外域规范脉冲初值、[1,3]^3、G=c=1、mass=1、
振幅 .001、固定 1+log/Gamma-driver 参数、SBP(4,2)、解析目标 SAT 或无投影 RK4。
三档 7/14/28 步，dt=1/(16*steps)，共同终点 T=1/16。所有旧阈值不变：
端点/阶段 det 偏差 <=1e-10，CFL<=.25*(1+1e-14)，特征代数残差<=2e-11，
基条件数<=1e6；独立诊断绝对差<=2e-12；时间差分辨下限2e-13、阶数3.5..4.5。
空间/约束收敛和真正物理边界没有因完成时间实验而自动成立。

仅调用已资格化 checkpoint v2 和 RK4 v1 二进制，不改它们的源码/格式/公式。
每段最多两步：第一步 native --plan 保存，第二步新进程 --restart 继续。
后续段从前一文件校验后读取全部58槽，原始计划记录前驱 checkpoint SHA，
整组 global plan 固定三档时间表、初值/目标/程序/源文件身份。不把修改计划的
新段说成同一个原始 native plan；独立审计逐段验证连接处状态、时间、边界一致。

另一已验 RK4 程序对同段作完整阶段对照，保存 q1/k1/.../q4/k4/endpoint，
每步端点必须与接受检查点逐字节一致。该对照是同方法的原生复算，不是独立
Einstein RHS 算法，不声称性能加速。保存 stdout 全字节，允许 zlib 无损压缩，
记录压缩文件与展开字节的 SHA，展开长度严格受限，不能用有损/删字段省空间。

## 验证与接受次序

1. 新运行器和独立审计器先通过定向测试，包括真实多段 native 计算、真实文件
   restart、原始RK重组、连接/目标/索引/元数据篡改，以及失败不升级接受前缀。
2. 所有案例在首次计算前登记。每段 plan/attempt 在可失败调用前保存。native
   已发布点与“完整轨迹、来源、独立诊断都通过”的科学接受点分开计数。
3. 阶段检查报告、原始 RK 组合、系数 SHA、原有代数门槛；每个科学接受端点
   计算原生产诊断与独立密集算子/Riemann 重建的 H/M 等五区域诊断，两者并列。
   对静态背景偏离不是解析正时间解误差。
4. 从已保存数据独立审计：不执行 RHS，不复用新运行器的链校验/算术/时间范数。
   所有前驱、计划、58槽、阶段整数标签、端点、摘要和诊断对应；部分批次只审计
   已接受前缀，不修改原失败。只有全三档结束才计算时间阶数；低于下限仍 unresolved。
5. 与旧 Python 首轮逐端点比较（逐槽/五区域归一化差<=2e-11）是移植对照，
   不称为逐位回放。旧 Python 超时回放和旧未解决的时间/空间问题均不重新评级。
