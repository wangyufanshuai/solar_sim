## 结论与判断尺度

目前是**具有真实 3D Einstein 方程演化组件、较完整复现链的数值相对论研究原型**。
它已不只是网页轨道演示，但还不是可用于生产黑洞/引力波研究的成熟求解器，
更不能称为世界前沿模型。BSSN/CCZ4、AMR、GPU 等名称本身不是前沿成果；
需要证明一个明确物理问题上的精度、稳定性、误差预算或性能优势。

本次判断来自当前代码、保存回执和本轮测试。历史回执数字不当作本轮重跑结果。
`NR-K1d / NR-K2c / NR-K3e` 是已实现分支标签，不表示 K1、K2、K3 全阶段验收完成。
网页 live 仍是受保护的 legacy EIH 路线；新科研内核只允许 shadow。

## 还需要多少轮：规划区间，不是成功承诺

真实计算 → 独立检查 → 保留通过或失败结论。仅新增文档、换报告编号、重复哈希
不算新科学轮次。下表是资源已可用且没有重大方程返工时的工程排期假设。

| 依赖顺序 | 工作包 | 估计有效轮次 | 关闭条件 |

| C | 稳健性与真实边界 | 3–5 | 多分辨率噪声/波传播；规范与约束入射模处理；边/角和反射误差；不能以静态解析目标冒充物理外边界 |
| D | 完整单黑洞与动态诊断 | 4–6 | 明确 puncture 或可接受 excision；约束收敛、稳定延长窗口、视界形状/质量、ADM 与提取半径误差闭环 |
| E | 真正的 3D AMR 演化 | 4–7 | 阶段一致 ghost fill、时间插值、跨层同步、动态重划分；约束/反射误差随分辨率下降；不是只测插值函数 |
| F | 非零辐射、碰撞再到轨道双黑洞 | 6–10 | 约束相容初值；多半径/分辨率波形的相位/幅值误差；质量/能量核算；与独立代码基准相符 |
| G | CPU 通过后 AMReX/CUDA | 2–4 | 原生工具链实测；同物理误差预算下跨后端一致性、显存/吞吐测试；允许结论为 GPU 不划算 |
| H | 独立复现与科研发布门禁 | 2–3 | 干净环境、版本/配置/证据打包、回滚、独立审阅；外部科学验收后才讨论 live |

累计：受控单黑洞约 **11–19 轮**；带真实 AMR 约 **15–26 轮**；
到具备误差预算的双黑洞目标约 **21–36 轮**；连同加速与发布约 **25–43 轮**。
这是工作量区间，不是统计置信区间，也不是“第43轮必达世界顶级”。
科学失败、强场不稳定、外部复现或算力不足都可能增加轮次；应按门槛重估。
“世界前沿”需要另外选定一个可发表、可独立检验的优势问题，无法用有限聊天轮数保证。

## 实施纪律与优先级建议

1. **先关一个有依赖的门槛。** 按用户最新选择，当前优先原生对等移植，随后回到
   共同物理初值的可分辨收敛与约束预算；不同时新增双黑洞、GPU、物质。
   资源超时不冒充数值失败，也不通过降低阈值绕过真实失败。
2. **把 Python 留作小规模参考。** 方法合同稳定后尽快做对应 C++ 实现；历史
   native 通过不能替代新方法移植。checkpoint 必须记录投影时机、离散算子、
   规范、边界、变量布局和方法版本，不能只记录数组和时间。
3. **初值和边界优先于看起来正常的轨迹。** 代数投影不是 Einstein 初值求解器。
   固定解析边界可测试方法，但不能证明真实辐射边界。AMR 几何系统的误差门禁
   应按其非守恒方程设计；不要机械套用流体守恒 reflux 作为全部充分条件。
4. **前沿目标后置，但从现在保留负结果。** 可以最终聚焦约束稳定边界、
   AMR 误差控制或可复现高效后端中的一个优势；先达到可信基线再选。
5. **证据输出也要预算。** C>=3GiB，E>=4GiB+32MiB，不清理用户文件、不降低底线。
   新长跑前先用实测单步成本估算计算量/存储。今后减少输出需另立保留策略，
   不能删除失败状态或牺牲独立诊断，只为多跑步数。

`shadow-only`；legacy 可回滚；所有物理、AMR、波形、GPU 与 live 准入标记
