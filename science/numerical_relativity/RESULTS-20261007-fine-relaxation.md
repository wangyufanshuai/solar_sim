比较 FD2/FD4、松弛率 lambda=0/1。主时间步 1/512，N24/32 另有 1/1024

其余 36 份是本次细网格两阶段的新样本，**不把复用样本算作新模拟**。

## Exa / GitHub 核查与后续建议

本轮针对验证方法做了定向 Exa 检索：5 个候选 URL、4 篇不同论文；进一步
读取了 Radia 等人的原始论文，并核查 GRChombo 的测试目录与约束测试源码。
不是全面的世界前沿排名，也没有在本机执行 GRChombo。

[Radia 等，2022](https://iopscience.iop.org/article/10.1088/1361-6382/ac6fa9)
通过与 Lean 比较研究二元黑洞波形，分别量化有限分辨率和有限提取半径误差；
还讨论 AMR 插值、网格切换和边界反射的影响。该文的部分黑洞计算使用
Sommerfeld 外边界：这不等于 CPBC 证明，也说明实际物理误差验证与理论边界
证明应分别记录，不能把边界公式的名称直接当作可靠性结论。

[GRChombo ConstraintTest](https://github.com/GRTLCollaboration/GRChombo/blob/main/Tests/ConstraintTest/ConstraintTest.cpp)
包含 C++ 与 Chombo Fortran 约束计算对照（检索时 blob SHA
`1fbf36192532181fc2ae6ec9a80a2ba7cae7d8da`）。这支持分层校验的工程方法，
不构成本项目已获得独立跨代码物理验证的证据。

建议按以下依赖顺序继续，不改变用户选定的单黑洞→双黑洞→物质主线：

1. 补齐与当前规范一致的非零曲率解析基准、辐射传播幅相误差测试；明确
   初始数据和检查点的场景身份，不能把其他物理解伪装成 gauge-wave。
2. 单黑洞验证必须独立控制外边界位置、空间／时间分辨率、内区处理和规范。
   量化约束、视界质量、ADM 与提取面敏感性；现有短程 proxy 不够。
3. 再验证 AMR 的插值、重网格与子步同步，并对 Psi4 波形分别报告网格误差、
   提取半径误差与独立成熟求解器差异。不能只检查“有波形输出”。
4. CPU 科学门禁通过后，再评估 AMReX/CUDA 的正确性与真实性能。
   当前 GPU 后端仍未验证，不能因机器有 RTX 4060 就宣称已可用。

完整约束传播、强双曲性、物理边界、黑洞演化、生产 AMR、物理视界／ADM、
波形精度、GPU 和 live 准入均仍是开放门禁。此次只关闭本文明确限定的
细网格有限时间窗门禁。
