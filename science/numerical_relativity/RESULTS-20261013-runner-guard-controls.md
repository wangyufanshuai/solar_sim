## 本轮关闭的三个运行器问题

| 原问题 | 修复 | 本轮证据范围 |
| --- | --- | --- |
| 单次精确复算卡住时，循环之间的超时检查无法打断它 | 数学导入、测试、复算和工作进程内完整性检查全部放入独立受监督进程树 | 睡眠模拟复算在 2.0 秒截止；清理前 4 个活动进程、清理后 0 个；没有执行真实能量复算 |
| 触发磁盘底线后，普通写入保护也会阻止失败回执 | 工作前预分配并验证两个 1 MiB 终态槽；收尾只覆盖既有槽，不额外分配空间 | 实际 Windows 文件分配检查通过；模拟 C/E 底线触发仍留下失败终态，普通新文件写入被拒绝 |
| KeyboardInterrupt/SystemExit 跳过普通异常处理，可能留下子进程 | Windows Job Object 管理本批次进程树，启动握手前完成归属，最终清理覆盖中断路径 | 中断、归属失败、残留后代和提前中断控制均通过；无关的合成测试进程未被误杀 |

Job Object 的后代归属、嵌套和关闭时终止语义依据
[Microsoft 官方说明](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)。
本轮证据是本机实测，不等价于所有 Windows 环境的验证。
