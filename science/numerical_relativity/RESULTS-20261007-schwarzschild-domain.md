# 原生 FO-CCZ4：Schwarzschild 外部区域基准通过

## 结论与项目水平

本轮把 Windows 原生 FO-CCZ4 从“仅支持周期单位立方体”推进到明确的
非周期、非零曲率真空基准。Python 参考实现、原生58变量演化、版本化重启
和独立几何检查已接通。预先规定的20组正时间收敛、6组初始曲率/约束收敛、
2组时间步对照和串行/多线程重放均通过。

这是**短时、固定解析边界的黑洞外部区域验证**，不是完整单黑洞模拟。
区域不包含视界或奇点，最长演化只有0.125M，尚未验证边界扰动传播后的稳定性。
当前仍属于有可复算证据的科研 shadow 内核，不能称为世界前沿生产级 NR 代码。

## 实现变化

- Native kernel `0.5.0`：新增 `schwarzschild-exterior`；原生 MSVC2022、
  C++17/OpenMP，沿用已有工具链，没有安装软件、修改系统 PATH 或声称 CUDA 可用。
- 正八分体立方体 `[1,3]^3`、M=1，全部位于各向同性坐标的 `r>M/2`。
  初态为静态 Schwarzschild，A/P 使用解析导数；h=I、K=a=Theta=beta=b=GammaHat=B=D=0。
- FD2/FD4 均固定最外两层节点，所有 RK 阶段将这两层的58槽 RHS 置零。
  内部全部独立演化，不填回解析解、不重构辅助变量、不投影或增加耗散。
- 新 checkpoint v5 保存区域上下界、质量、边界策略、固定层数及原有规范/控制参数。
  读取需要显式匹配；边界值损坏拒绝，不静默修补。旧 v1-v4 布局保留。
- 独立检查从 `gamma=h/chi` 和 `Kij=(a+hK/3)/chi` 重建 ADM 约束、Ricci 和
  真空 Weyl 曲率不变量。导数权重由多项式矩条件生成，不读取演化的 GammaHat/A/B/D/P。
  不满足真空约束时，Weyl 重建值只是诊断量，不冒充独立四维度规的精确 Kretschmann 标量。

新增边界目前只对本次 **FO** 路径开放；不是所有二阶 BSSN/通用诊断接口的边界扩展。
实验规范 `f=3 alpha chi, mu=.2 chi` 继续保持显式 opt-in；本轮没有证明其全域强双曲性。

N=17/25/33；主时间步1/256；t=0、1/16、1/8，共6个主案例、18个样本。
比较严格使用相同的125个物理位置 `[1.5,2.5]^3`，不是随网格变化的全域平均。

两次正时间的20组均为实测阶，不是“低于噪声底”替代通过；6组初始收敛也通过。
N33/FD4/t=.125 的状态 RMS 误差 `1.09925e-9`，H=`2.21417e-7`，
M=`5.43051e-9`。这里“约束通过”指残差随网格收敛，不是残差等于零。

这只支持时间误差污染很小，不是一次独立的 RK4 时间收敛阶测量。
