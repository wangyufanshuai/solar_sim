# 从外部区域基准到可用黑洞边界：仍缺什么

## 范围与证据等级

本文件是下一阶段设计分析，不是新的边界实现、已执行实验或物理准入证书。
遵循 academic-research-suite 的“先冻结判据，再运行”流程；Exa 用于定向发现，
GitHub 用于核读原始代码。没有安装、运行或复制外部求解器。

当前 Schwarzschild 原生路径的两层解析固定 halo 适合校验离散方程和重启。
区域不含视界；它既不是穿刺演化，也不是已验证的吸收边界。
延长时间或移动边界本身，不能把这种测试边界变成物理边界。

## 外部核查支持的两点

1. Ruiz、Hilditch、Bernuzzi 的 [Z4c 边界论文](https://arxiv.org/html/1010.0523v2)
   区分约束保持与吸收性能；证明包含冻结系数等假设，文中的主要数值测试使用球对称约化。
   它不是本项目58变量 FO-CCZ4 的现成边界定理。论文 V.2 的远边界参考、传播后收敛和
   特征入/出射量分析，为后续实验设计提供思路；不能照搬其误差改善数值或反射结论。
2. 核读 [GRChombo 的 Sommerfeld 实现](https://github.com/GRTLCollaboration/GRChombo/blob/main/Source/GRChomboCore/BoundaryConditions.cpp#L593-L660)：
   它逐分量使用径向导数与渐近值衰减项，边缘使用二阶单边导数。
   这是一条明确的工程实现路径，不是对所有 FO-CCZ4 约束的边界证明。
   核读文件与 Git blob `98bd0d571fe34833211b1ed767669c56545de799` 内容相同。

本次 Exa 定向检索请求5条候选；HTML/PDF/机构镜像不能重复算作独立论文支持。
以上不是全面文献综述，也没有声称穷尽了现有边界方法。

## 本地代码的真实边界

| 本地能力 | 已实现内容 | 不能据此声称 |
|---|---|---|
| `fo_ccz4_schwarzschild.py` / 原生0.5.0 | 解析初态、固定 halo、闭合区域身份 | 吸收边界、完整黑洞 |
| `fo_ccz4_rhs.py::_apply_sommerfeld_proxy_rhs_fo_3d` | 所有基础/辅助场的标量出射代理 | CPBC、特征分解或辐射边界 |
| `fo_ccz4_frozen_characteristics.py` | 给定背景点的58维特征空间数值检查 | 全系数域强双曲性、平滑有界特征基 |
| `fo_ccz4_characteristic_boundary_shadow.py` | Minkowski 线性化 SAT 边界接线 | 非线性、变系数 Einstein 边界闭合 |
| `fo_ccz4_full_cpbc_energy_shadow.py` | 冻结系统的约束映射及候选能量检查 | 非线性 CPBC 或真实波形有效性 |

因此，下一阶段不能只给已有 Sommerfeld 代理改名，或把冻结特征检查的通过状态
直接写成 `physical_boundary_validated=true`。

## 建议的实施次序与停止条件

1. **完成当前固定方程的误差分离。** 补齐 FD2/FD4、移动边界、时间步减半和
   重放矩阵。原长窗口超时收据保持失败；分段完成的数据另列来源和累计成本。
   未完成对照时，不把误差增长归因于边界，也不宣称内部空间阶已证明长期维持。
2. **冻结实际58变量的边界合同。** 明确左右面的法向与 RHS 符号、实际规范速度、
   辅助约束、入射/出射/零速分量、边角重复施加规则，以及初始数据与边界数据的相容性。
   不用“把所有入射量设零”代替规范、约束和物理辐射数据的分别指定。
3. **验证离散边界算子。** 独立检查矩条件、边界闭合阶和适用时的 SBP/SAT 能量性质；
   点值特征基失秩、条件数失控或模板不匹配时明确拒绝，不用伪逆或隐藏投影修补。
4. **做可定位的边界扰动实验。** 在平直背景及曲率背景分别发送受控扰动；固定同一
   物理测区，使用多分辨率、至少两个边界位置及时间步对照。记录波离开和返回后的
   H/M、Z4、A/B/D/P 与入/出射量；不同边界位置的差值不是自动成立的反射系数。
   每个实验需事先给出可测量阈值、噪声底和执行资源上限。
5. **再进入含视界的单黑洞。** 另行选择穿刺或切除的数据/规范/数值处理，验证长期
   稳健性、视界与质量一致性。随后才讨论 AMR 接口反射、双黑洞和波形误差预算。

当前没有足够证据选择一个“已经正确”的非线性 CPBC。上述次序是本项目的工程判断，
不是引用论文已经替我们完成的证明。CPU 物理门禁未闭合前，CUDA 加速不改变结论。
